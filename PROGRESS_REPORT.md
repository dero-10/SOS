# Laporan Progres Mingguan SOS (Student on Study) — Minggu 10–12

## Minggu 10

Pada minggu ini saya memperluas lapisan data dan membangun alur penemuan helper serta balasan request. Saya menambahkan tabel `helpers`, `help_history`, `replies`, dan `chat_messages` di Room beserta DAO dan repository-nya (Helper, Reply, Chat), lalu membuat data seed berisi akun demo, 9 helper, 7 request komunitas lengkap dengan balasan, 5 percakapan chat, dan riwayat bantuan. Bottom bar kini memiliki lima tab sesuai desain Figma (Home, Explore, Chat, Recent, Profile), tab Explore sudah memiliki tab Helper, dan halaman profil helper sudah jadi dengan tombol "Chat Helper". Saya juga membuat halaman detail request dalam dua varian (milik orang lain, dan milik sendiri dengan header teal serta ikon pensil untuk edit) lengkap dengan daftar balasan dan jumlah balasan yang ter-update langsung lewat Flow di kartu request. Total ada 4 commit dengan sekitar 1.500 baris kode baru.

## Minggu 11

Minggu ini fokus pada chat, aktivitas terbaru, dan penyelesaian halaman Profile serta tampilan. Saya membuat daftar chat, detail chat, dan alur "Chat Helper" (profil helper → Add Request Details → Send) yang menyimpan request privat, tidak menampilkannya di feed Explore, dan mengirim pesan pertama "Request has been sent." ke chat. Tab Recent dibuat dengan aktivitas yang dikelompokkan per tanggal (tidak ada frame Figma untuk tab ini, jadi tampilannya mengikuti interpretasi sendiri). Halaman Profile dilengkapi badge LinkedIn, edit data dengan validasi, serta dialog Withdraw dan Buy Credits yang memperbarui saldo di Room (simulasi tanpa backend pembayaran), lalu lampiran gambar pada request kini dipilih dari file sungguhan dan ditampilkan sebagai pratinjau. Font aplikasi diganti ke Inter sesuai Figma, dan `PROGRESS.md` serta `README.md` diperbarui. Dengan ini semua 9 frame Figma sudah diimplementasikan dan diperiksa di emulator (semua tab, profil helper, alur Chat Helper, balasan, dan Buy Credits), dengan total 6 commit.

## Minggu 12 (rencana)

Minggu 12 direncanakan untuk menguji, merapikan, dan menambah fitur yang belum ada. Pertama, saya akan menguji alur yang belum sempat dicoba di emulator, yaitu pemilihan gambar, Withdraw, edit dan hapus request, kolom LinkedIn, serta rotasi layar pada halaman baru, lalu memperbaiki bug yang ditemukan. Kedua, saya akan mengganti `fallbackToDestructiveMigration` dengan migrasi Room yang sebenarnya agar data pengguna tidak terhapus saat skema berubah, dan membersihkan gambar request yang sudah tidak terpakai di penyimpanan aplikasi. Ketiga, jika waktu cukup, saya akan menambahkan dark mode (warna di `SosTheme.kt` dibuat mengikuti tema) dan bahasa Indonesia, yang saat ini baru tampil sebagai "Coming soon" di Profile. Terakhir, saya akan menyiapkan build bersih, akun demo, dan screenshot setiap layar untuk demo serta pengumpulan akhir.
